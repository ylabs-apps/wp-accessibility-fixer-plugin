# WP Accessibility Fixer

Find and fix supported accessibility issues on your WordPress site: image alt text, headings and link text. Every fix is previewed and can be undone.

## Use it

1. Install the plugin, then connect WP Accessibility Fixer using Claude's connection and authentication flow.
2. Ask Claude in plain words, for example: "Check my WordPress site for accessibility issues and fix the missing alt text."
3. Claude uses the included skill: it looks first, shows what it plans to change, and asks for your approval before making changes.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://mcp.wpaccessibilityfixer.com/mcp. Tool requests are handled by WP Accessibility Fixer (https://www.wpaccessibilityfixer.com/privacy/). This bundle contains no separate storage service.
